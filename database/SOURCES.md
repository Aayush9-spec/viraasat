Viraasat is a **commercial** marketplace. Every dataset below was vetted for
commercial-safe use. Scraped marketplace dumps are **excluded** from live
listings by policy (see table).

## Evaluated but REJECTED for live listings (commercial risk)

- **IndusCraft** (HuggingFace `vedantjadhav701/induscraft-dataset`): ideal schema fit
  (craft + region + images), but the dataset was **gated (HTTP 401, auth required)**
  at time of evaluation (2026-09-04). Re-evaluate if it becomes public with a
  commercial-compatible license. Do not use without confirming the license card.
- **JHARIDOSS Indian jewellery bucket** (HuggingFace): schema-rich (name, INR price,
  features, images) but **scraped from jiomart.com** — marketplace ToS risk.
  Permitted only for *internal* pricing-model experiments, never for displayed listings.
- **Amazon India 1.5M / Myntra fashion dumps** (Kaggle): scraped, mass-market, noisy.
  Same policy: experiments only, never live catalog.
- **IndoFashion** (106K images): access gated behind a request form; no prices.
  Revisit if access is granted and license allows commercial use.

## Rules for adding new catalog data

1. Only artisan-supplied content or explicitly commercially-licensed sources.
2. Every new source gets a row in the table above **before** its data lands in `products.json`.
3. Images must be rehosted (Firebase Storage); never hotlink third-party URLs.
4. Run `scripts/seed_catalog.py --dry-run` first; merge only on a clean report.
